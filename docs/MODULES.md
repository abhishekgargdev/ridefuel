# Core Application Modules Catalog

RideFuel includes 20 fully working modules:

| # | Module | Route | Purpose |
|---|---|---|---|
| 1 | **Public Home Page** | `/` | Hero section, motorcycle fuel problem explanation, instant demo CTA, feature highlights |
| 2 | **Features Page** | `/features` | Technical breakdown of algorithms, PWA capabilities, and telemetry tracking |
| 3 | **About Page** | `/about` | Story of the 2022 Classic 350 J-series engine, mission, Privacy, Terms, Contact |
| 4 | **Login** | `/login` | Secure JWT user authentication with 1-click Demo Account login button |
| 5 | **Sign Up** | `/signup` | User registration with automatic Classic 350 default bike provisioning |
| 6 | **Forgot Password** | `/forgot-password` | Initiates password reset flow and issues secure reset token |
| 7 | **Reset Password** | `/reset-password` | Updates password hash using verified single-use reset token |
| 8 | **Dashboard** | `/dashboard` | Mobile-first cockpit: 12 KPI cards, 8 charts, time filters (7d, 30d, 3m, 6m, 1y) |
| 9 | **Bike Management** | `/dashboard/bikes` | Multi-bike management: add, edit, delete, switch active motorcycle |
| 10 | **Fuel Logs** | `/dashboard/fuel` | Fuel refill logs: volume, price/L, full-tank indicator, distance since last fill, mileage |
| 11 | **Daily Readings** | `/dashboard/readings` | Speedometer checkpoint entry with odometer decrease protection & rollback override |
| 12 | **Mileage Analytics** | `/dashboard/mileage` | Deep dive into full-tank vs partial fills, min/max/average/recent fuel economy |
| 13 | **Fuel Analytics** | `/dashboard/fuel-analytics` | Petrol price trends over time, station breakdown, monthly volume consumption |
| 14 | **Range Calculator** | `/dashboard/range-calculator` | Algorithmic Estimated Fuel & Range telemetry + interactive trip simulation slider |
| 15 | **Expenses** | `/dashboard/expenses` | Multi-category expense tracking: Insurance, Cleaning, Tolls, Gear, Parking, Repairs |
| 16 | **Maintenance** | `/dashboard/maintenance` | Upcoming and overdue service tracker with dual criteria (target odometer or date) |
| 17 | **Service History** | `/dashboard/service-history` | Official chronological workshop maintenance ledger and parts invoice archive |
| 18 | **Reports** | `/dashboard/reports` | Consolidated monthly and yearly financial statements with cost-per-km breakdown |
| 19 | **Profile** | `/dashboard/profile` | Rider details, measurement units (km / miles, L / gal), and currency preferences |
| 20 | **Settings** | `/dashboard/settings` | PWA cache management, installation triggers, and 1-click factory demo data reset |
